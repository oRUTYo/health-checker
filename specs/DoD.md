# Definition of Done (DoD) — AI Feature

---

## 1. Общие критерии (для любой задачи)

Задача считается выполненной, если:

1) Код написан и работает без ошибок
2) Нет критических багов

---

## 2. AI (ML модель)

Готово, если:

3) Данные из ECG Heartbeat Categorization Dataset загружены и предобработаны
4) Есть обученная baseline модель
5) Достигнуты метрики:
  - Accuracy ≥ 85%
  - F1-score ≥ 0.80
6) Модель сохраняется (например `.pkl` / `.pt`)
7) Есть inference-скрипт (принимает сигнал → возвращает предсказание)
8) Время инференса ≤ 2–3 секунд
9) Есть простой лог (ошибки/предсказания)

---

## 3. Backend

Готово, если:

10) Реализован API endpoint:
  - `POST /predict`
11) Backend:
  - принимает входные данные (JSON / файл)
  - вызывает AI модель
  - возвращает:
    - класс
    - confidence score
12) Обработка ошибок:
  - некорректный формат
  - пустой ввод
13) Ответ API < 1 сек (без учета ML)

---

## 4. Frontend

Готово, если:

14) Есть простой UI:
  - загрузка файла / ввод данных
  - кнопка "Analyze"
15) Отображается:
  - результат классификации
  - вероятность
- Есть визуализация сигнала (простая линия)
- Обрабатываются ошибки (например “не удалось загрузить”)
- Интерфейс работает в браузере без критических багов

---

## 5. Интеграция (E2E)

Готово, если:

16) Frontend → Backend → AI работает как единая система
- Пользователь может:
  1. Загрузить ECG
  2. Нажать Analyze
  3. Получить результат
17) Весь сценарий занимает ≤ 5 секунд
18) Нет критических падений
